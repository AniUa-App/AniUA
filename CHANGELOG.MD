# Changelog

## [0.1.0]

### Нові функції

- **Фонове зображення на сторінці аніме** — обкладинка тепер відображається як розмитий фон з градієнтним ефектом у верхній частині сторінки
- **Спрощений вибір плеєра** — замість bottom sheet тепер простий перемикач "Вбудований плеєр" у налаштуваннях

### Виправлення

- Кнопка "Дивитись" тепер коректно показує стан: "Завантаження", "Продовжити", "Немає перекладу" або "Почати перегляд"
- Відсутність перекладу (404) більше не показує екран помилки — замість цього відображається кнопка "Немає перекладу"
- Пошук тепер коректно передає фільтри при їх застосуванні
- Жанри в інформації про аніме відображаються коректно (без зайвих коми)
- Виправлено опечатку у назві вкладки навігації ("Орбані" → "Обрані")
- Fallback на HikkaApiComplete тепер використовує правильний метод `getAnimeEpisodes()`

### Зміни

- **Новий URL API** — `https://api-aniua.yuzka.site` → `https://api.aniua.app`
- **Видалено систему APK-оновлень** — залишились лише OTA-оновлення через Expo
- Додано залежність `html-entities`
- Оновлено `react-native-nitro-modules` до `^0.35.2`
